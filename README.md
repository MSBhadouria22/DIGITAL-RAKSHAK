## Overview

DIGITAL-RAKSHAK is an advanced security analysis tool tailored for Android applications, enabling rapid detection and in-depth analysis of potentially malicious APKs. It combines static decompilation, permission scrutiny, URL extraction, and dynamic runtime monitoring to provide a holistic view of app behavior and security risks.

## Why DIGITAL-RAKSHAK?

This project aims to enhance mobile security by transforming suspicion into actionable insights. The core features include:

🔍 **Static Analysis**: Decompiles APKs to identify suspicious permissions and embedded URLs, aiding threat detection.

🔍 **Dynamic Monitoring**: Executes apps in emulators to observe runtime behaviors, network activity, and app interactions.

⚡ **Threat Scoring**: Integrates static and dynamic data to generate comprehensive risk assessments using teh AI predictive model.

📊 **User-Friendly Dashboard**: An intuitive web interface for uploading APKs and visualizing detailed security reports.

🔄 **Seamless Workflow**: Supports integration into broader security and reverse engineering processes for efficient threat mitigation.

## Getting Started

### Prerequisites

This project requires the following dependencies:

- **Programming Language**: Python, HTML, CSS, Javascript, Android Studio packages
- **Package Manager**: Conda

### Installation

Build DIGITAL-RAKSHAK from the source and install dependencies:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/MShadour122/DIGITAL-RAKSHAK
   ```

2. **Navigate to the project directory**:
   ```bash
   cd DIGITAL-RAKSHAK
   ```

3. **Install the dependencies**:
   
   Using **conda**:
   ```bash
   conda env create -f conda.yml
   ```

## Usage

Run the project with:

Using **conda**:
```bash
conda activate {venv}
python {entrypoint}
```
